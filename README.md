# Express Booking Automation

## Project Overview
This project contains Selenium WebDriver automation for the StarClinch Express Booking module.

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Eclipse IDE

## Application URL
https://sv2.starclinch.com/express-booking/

## Test Coverage
- Page title and URL verification
- Browser launch and navigation
- Screenshot capture on test failure
- Cross-browser testing

## Test Execution
Run ExpressBookingTest.java as TestNG Test.

## Note
The staging application returned a 522 Connection Timed Out error during testing, which blocked the complete booking flow.
